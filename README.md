# Recipe Finder 🍽️

تطبيق لاستكشاف وصفات الطعام، تصفحها حسب التصنيف، والاحتفاظ بالوصفات المفضلة في مكان واحد. هذا المشروع تطبيق عملي ضمن تدريب Flutter في **أكاديمية CS**، وتم بناؤه بهدف تطبيق مفاهيم بناء تطبيقات Flutter الحديثة وربطها بخدمات خارجية.

## نبذة عن المشروع

يوفر التطبيق تجربة بسيطة للبحث عن الوصفات واستكشاف تفاصيلها، مع نظام حسابات للمستخدمين وإمكانية حفظ الوصفات المفضلة. يتم جلب بيانات الوصفات من [TheMealDB](https://www.themealdb.com/)، بينما تُستخدم [Supabase](https://supabase.com/) للمصادقة وبيانات الملف الشخصي.

## المميزات

- تسجيل الدخول وإنشاء حساب جديد.
- استعادة كلمة المرور وتحديثها عبر البريد الإلكتروني.
- تسجيل الدخول باستخدام Google عبر Supabase OAuth.
- استعراض تصنيفات الوصفات والبحث بينها.
- عرض الوصفات حسب التصنيف.
- عرض تفاصيل الوصفة، المكونات، التعليمات، والمصدر على YouTube عند توفره.
- إضافة الوصفات إلى المفضلة وإزالتها.
- حفظ المفضلة محليًا باستخدام `SharedPreferences`.
- صفحة ملف شخصي تعرض بيانات المستخدم وخيارات الحساب.
- معالجة حالات التحميل والأخطاء مع إمكانية إعادة المحاولة.
- شاشة بداية مخصصة ودعم التنقل بين أقسام التطبيق.

## التقنيات المستخدمة

- **Flutter / Dart** لبناء التطبيق.
- **flutter_bloc** لإدارة الحالة باستخدام Cubit.
- **Dio** للتعامل مع طلبات TheMealDB API.
- **Supabase** للمصادقة وبيانات المستخدم.
- **GetIt** لحقن الاعتماديات.
- **SharedPreferences** للتخزين المحلي للمفضلة وبعض الإعدادات.
- **Dartz** للتعامل مع نتائج العمليات والأخطاء.

## بنية المشروع

يتبع المشروع تنظيمًا قائمًا على الميزات، مع فصل طبقات العرض والبيانات والخدمات المشتركة:

```text
lib/
├── core/
│   ├── common/             # أدوات التحقق والمكونات المشتركة
│   ├── constants/          # النصوص، المسارات، ونقاط الاتصال
│   ├── dependency_injection/
│   ├── networking/         # تهيئة Supabase
│   ├── routing/            # المسارات والتنقل
│   ├── services/           # API، التخزين، ومعالجة الأخطاء
│   └── themes/             # الألوان والثيمات
├── features/
│   ├── auth/               # تسجيل الدخول وإنشاء الحساب واستعادة كلمة المرور
│   ├── favorites/          # إدارة الوصفات المفضلة
│   ├── home/               # التصنيفات والوصفات وتفاصيلها
│   ├── main_home/          # التنقل الرئيسي
│   └── profile/            # الملف الشخصي وإعدادات الحساب
├── food_app.dart
└── main.dart
```

## المتطلبات

- Flutter SDK متوافق مع Dart `3.10.4` أو أحدث ضمن نفس سلسلة Flutter.
- Android Studio أو Xcode أو أي بيئة تدعم تشغيل Flutter.
- اتصال بالإنترنت للوصول إلى TheMealDB وSupabase.
- مشروع Supabase مفعّل عليه Email Authentication، وGoogle OAuth إذا رغبت في استخدام تسجيل الدخول عبر Google.

## التشغيل محليًا

1. استنسخ المشروع وانتقل إلى مجلده:

   ```bash
   git clone <repository-url>
   cd food_app
   ```

2. ثبّت الاعتماديات:

   ```bash
   flutter pub get
   ```

3. راجع إعدادات Supabase في `lib/core/networking/supabase_service.dart`، وتأكد من إعداد رابط إعادة التوجيه في إعدادات المصادقة والمنصات.

4. شغّل التطبيق على جهاز أو محاكي:

   ```bash
   flutter run
   ```
